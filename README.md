# Kaggle-Data-Science-Code

This is a compelation of all Kaggle data science challanges I attempt.


## Formating 

- Attempts are seperated into seperate folders, labeled : 📁 [Challange name] - [Attempt Number]

- Within these attempt files:
        - 📁 data : all downloaded data from the Kaggle challange 
        - 📄 prediction.ipynb : code for training models
        - 📄 submission.csv : predictions made by model, the uploaded Kaggle submission
