# Kaggle-Data-Science-Code

This is a compilation of all Kaggle data science challanges I have attempted.


## Formating 

- Attempts are seperated into seperate folders, labeled : 📁 [Challange name] - [Attempt Number]

- Within these attempt files:<br>
        - 📁 data : all downloaded data from the Kaggle challange <br>
        - 📄 prediction.ipynb : code for training models<br>
        - 📄 submission.csv : predictions made by model, the uploaded Kaggle submission <br>
